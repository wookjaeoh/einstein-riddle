# 클릭 픽&플레이스 · 손 커서 설계

**날짜:** 2026-09-15  
**상태:** 설계 승인됨, 구현 계획 대기  
**기준 구현:** `einstein-riddle-app/` (배포본 이후)

## 1. 목표

1. 카드를 **한 번 클릭해 집고**, 포인터를 따라 자유롭게 이동한 뒤 **슬롯/풀을 다시 클릭해 놓는다.** (누르고 끌기 불필요)
2. PC에서 카드 위·집은 상태에 **오른손 커서**를 쓰고, 집은 동안 **움켜쥔** 시각 피드백을 준다.
3. PC·태블릿 동일 동작.

## 2. 확정 선택

| 항목 | 선택 |
|------|------|
| 입력 | A — 전 플랫폼 탭/클릭 집기·놓기 |
| 커서 | A — CSS 커스텀 손 커서(펼침/움켜쥠) |
| 구현 | 클릭 토글 픽업 + 포인터 추적 고스트 |

## 3. 동작

| 입력 | 결과 |
|------|------|
| 카드 클릭 (미집기) | 집기: 원본 `picked`/반투명, 고스트 생성, `body.holding-card` |
| 포인터 이동 | 고스트 추적, 유효 슬롯/풀 `drop-target` |
| 같은 카테고리 슬롯 클릭 | `onDrop` → 슬롯에 배치, 집기 해제 |
| `#pool` 클릭 | 풀로 되돌리기 |
| 빈 곳 클릭 / Esc | 취소(집기만 해제) |
| `isLocked()` | 집기·놓기 무시 |

기존 `onDrop({ value, category, to })` 계약은 유지한다.

## 4. 커서·시각

- `assets/cursors/hand-open.svg` — 카드 hover
- `assets/cursors/hand-grab.svg` — 집은 상태 (`body.holding-card`)
- CSS: `cursor: url("…") x y, grab/grabbing` 폴백
- 고스트: 약간 scale·그림자
- 터치: 커서는 OS에 맡김

## 5. 파일

| 파일 | 변경 |
|------|------|
| `js/drag-drop.js` | 클릭 토글 픽&플레이스 |
| `css/styles.css` | 커서·picked·holding-card·고스트 |
| `assets/cursors/*.svg` | 손 커서 |
| `tests/run-tests.mjs` | 집기→놓기·취소·잠금 회귀 |

## 6. 성공 기준

1. 클릭만으로 집기·이동·놓기가 된다.
2. PC에서 손 커서가 펼침/움켜쥠으로 바뀐다.
3. 잠금·새 문제·정답 공개와 충돌하지 않는다.
4. 기존 테스트 + 새 픽&플레이스 테스트 통과.
