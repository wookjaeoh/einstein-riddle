# 아인슈타인 추론 게임 — 난이도·힌트·다크 UI 개편 설계

**날짜:** 2026-09-08  
**상태:** 구현 완료, 실기기 수업 전 검증 대기  
**기준 구현:** `einstein-riddle-app/` (`fd633a5` 이후, Task 5 문서 커밋 포함)

### 검증 수치 (2026-09-15)

- 자동 테스트: `125 passed, 0 failed`
- 벤치(난이도별 10회): easy avg ~4ms·폴백 0; normal avg ~9ms·폴백 0; hard avg ~613ms·폴백 2; expert avg ~1012ms·폴백 4
- 비폴백 단서: hard 15 > expert 14
- 모든 결과 유일해 또는 검증된 폴백

## 1. 목표

기존 5집 추론 게임을 고2 수업에서 반복 활용할 수 있도록 난이도를 4단계로 세분화하고, 집 수·속성 수·단서 수를 난이도에 맞게 바꾼다. 단서 클릭 강조를 제거하고 별도 단계형 힌트를 제공한다. 교사 패널은 삭제하며, 화면은 큰 글씨를 지원하는 전문적인 다크블루 스타일로 개편한다.

## 2. 확정 요구사항

### 2.1 난이도

| ID | 표시명 | 집 수 | 카테고리 | 생성 단서 정책 |
|---|---|---:|---|---|
| `easy` | 쉬움 | 4 | 색·국적·음료·음식 | 10~12개 |
| `normal` | 보통 | 4 | 색·국적·음료·음식·동물 | 12~14개 |
| `hard` | 어려움 | 5 | 5개 전부 | 15개 내외 |
| `expert` | 매우 어려움 | 5 | 5개 전부 | 유일해 유지 최소 집합, 주로 12~14개 |

- 4집 문제는 각 카테고리의 5개 값 중 4개를 매 문제 무작위 선택한다.
- 모든 문제는 솔버로 유일해를 검증한다.
- 목표 단서 구간을 맞추지 못해도 유일해인 문제가 있으면 사용할 수 있으며 실제 단서 수를 UI에 표시한다.
- 생성 시간 제한을 넘기면 해당 난이도 전용 검증된 폴백 문제를 사용한다.

### 2.2 단서와 힌트

- 단서 클릭은 관련 집·카드 강조를 하지 않는다.
- 단서 클릭은 `읽음/읽지 않음` 표시만 토글한다.
- 별도 `힌트 보기` 버튼을 제공한다.
- 힌트는 하단 힌트 패널에 번호를 붙여 누적한다.
- 힌트는 다음 순서로 점차 구체화한다.
  1. 추론 방향
  2. 함께 볼 단서 안내
  3. 확정 가능한 사실
- 횟수 제한은 없지만, 현재 문제에 준비된 힌트를 모두 공개하면 “더 이상 제공할 힌트가 없습니다.”를 표시한다.
- 새 문제·난이도 변경 시 읽음 표시와 힌트 기록을 초기화한다.

### 2.3 교사 기능 제거

- 상단 `교사` 버튼, 비밀번호 입력, 정답 표, 현재 배치 비교를 삭제한다.
- `teacher.js`와 교사 전용 테스트를 삭제한다.
- 정답은 학생 UI와 DOM에 직접 렌더링하지 않는다.

### 2.4 시각 디자인

선택안: **A. 네이비 데이터랩**

- 페이지 배경: `#071525`
- 패널: `#0D2238`
- 보조 패널: `#102A44`
- 테두리: `#24415E`
- 주요 글자: `#E8F2FF`
- 보조 글자: `#A8BDD2`
- 강조: `#64D9FF`
- 성공: `#5DE0A3`
- 오류: `#FF7B8A`
- 그라데이션과 그림자는 절제하고, 얇은 경계와 높은 명암 대비를 사용한다.

레이아웃:

1. 상단: 제목, 난이도, 새 문제, 타이머, Undo, 초기화, 제출
2. 데스크톱 왼쪽: 단서 목록
3. 데스크톱 중앙: 4집 또는 5집 보드와 카드 풀
4. 하단: 힌트 버튼·힌트 기록·제출 피드백
5. 태블릿: 단서 → 보드 → 힌트 순서의 세로 배치

### 2.5 글자 크기 조절

- 기본 글자 배율: **150%**
- 오른쪽 하단 고정 컨트롤: `− 150% +`
- 1회 클릭: 10% 변경
- 최소 100% (기본에서 축소 5회)
- 최대 200% (기본에서 확대 5회)
- 한계에서 해당 버튼 비활성화
- 선택값은 `localStorage`에 저장하고 다음 방문 시 복원
- CSS 사용자 변수로 글자·버튼·카드·슬롯 높이를 함께 조절한다.
- 컨트롤에 `aria-label`을 제공하고 현재 배율은 `aria-live`로 알린다.
- 확대 시 보드는 가로 스크롤을 허용하며 카드 텍스트를 자르지 않는다.

## 3. 아키텍처

### 3.1 난이도 프로필

`puzzle-data.js`:

```js
DIFFICULTY_PROFILES = {
  easy:   { houseCount: 4, categories: [...4개], clueRange: [10, 12] },
  normal: { houseCount: 4, categories: [...5개], clueRange: [12, 14] },
  hard:   { houseCount: 5, categories: [...5개], clueRange: [15, 15] },
  expert: { houseCount: 5, categories: [...5개], clueRange: [12, 14], minimize: true },
}
```

각 생성 결과는 다음 런타임 구성을 포함한다.

```js
{
  houseCount,
  categories,
  values,
  answer,
  clues,
  hints,
  difficulty,
  meta
}
```

### 3.2 모듈 변경

| 파일 | 변경 |

| `puzzle-data.js` | 4개 난이도 프로필·난이도별 폴백 |

| `generate.js` | 프로필 기반 값 선택·정답·단서·힌트 생성 |

## 4. 데이터 흐름

1. 난이도 선택 또는 새 문제 클릭
2. `DIFFICULTY_PROFILES[difficulty]` 조회
3. 4집이면 카테고리별 값 4개 무작위 선택
4. 정답 세계와 단서 후보 생성
5. 가변 솔버로 유일해 검증·단서 조절
6. 단계형 힌트 목록 생성
7. `state.loadPuzzle(runtimePuzzle)` 호출
8. 보드·단서·카드·힌트 UI 초기화

## 5. 오류·경계 처리

- 생성 제한시간 초과: 난이도별 폴백 사용
- 폴백도 현재 프로필의 집 수·카테고리 수와 일치해야 한다.
- 준비된 힌트 소진: 종료 문구만 추가하고 상태 변경 없음
- 잘못된 `localStorage` 배율: 150%로 복구
- 확대·축소 한계: 버튼 비활성
- 난이도 변경 취소: 이전 선택값 복구
- 초기화: 현재 문제·힌트·읽음 표시는 유지하고 카드 배치만 초기화
- 새 문제: 배치·Undo·타이머·힌트·읽음 표시 모두 초기화

## 6. 테스트

자동 테스트:

- 4개 난이도 프로필의 집 수·카테고리·단서 정책
- 4집 문제에서 카테고리별 값이 정확히 4개이며 유효한 원본 값의 부분집합인지
- 쉬움 문제에서 `animal`이 answer·values·clues에 존재하지 않는지
- 가변 솔버가 4×4, 4×5, 5×5 문제의 해를 정확히 계산하는지
- 생성 answer가 모든 단서를 만족하며 해가 정확히 하나인지
- 어려움과 매우 어려움의 비폴백 단서 수 차이
- 읽음 토글이 힌트 상태를 변경하지 않는지
- 단계형 힌트 순서·누적·소진
- 새 문제에서 힌트·읽음 상태 초기화
- 배율 100~200% 제한·저장·복원
- 교사 요소·import·테스트가 남지 않는지

수동 테스트:

- Chrome/Edge에서 네 난이도 각각 새 문제 3회
- 4집/5집 보드 드래그·교체·Undo·제출
- 배율 100%, 150%, 200%에서 잘림·겹침·가로 스크롤
- 태블릿에서 드래그와 오른쪽 하단 배율 컨트롤
- 프로젝터에서 다크블루 대비와 150% 글자 가독성

## 7. 범위 밖

- 학생 계정·점수 서버 저장
- 교사 패널·학생 진행 대시보드
- 사용자가 문제 내용을 직접 편집하는 기능
- 집 수를 사용자가 임의 입력하는 기능
- 힌트 사용에 따른 점수 감점

## 8. 성공 기준

1. 네 난이도가 명시된 집 수·카테고리로 문제를 생성한다.
2. 모든 생성 문제는 유일해이거나 검증된 난이도별 폴백이다.
3. 단서 클릭은 읽음 표시만 바꾸며 힌트는 별도 버튼에서만 나온다.
4. 교사 UI·코드가 제거된다.
5. 기본 150%, 100~200% 배율 조절이 저장·복원된다.
6. 네이비 데이터랩 테마가 100%, 150%, 200%에서 사용할 수 있다.
