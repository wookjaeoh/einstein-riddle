# 아인슈타인 추론 게임 (수업용)

고2 대상. 단서를 읽고 집의 색·국적·음료·음식·(난이도에 따라)동물을 배치하는 **알고리즘 생성형** 추론 웹앱.

## 실행 방법

`einstein-riddle-app` 폴더에서:

```bash
npx --yes serve . -l 4173
```

브라우저에서 `http://localhost:4173` 로 연다.  
(`file://` 직접 열기는 ES module 때문에 실패할 수 있음)

USB 폴더 복사·오프라인 수업도 가능. 인터넷은 `npx serve` 최초 실행 시에만 필요할 수 있다.

## 난이도

| 난이도 | 집 수 | 카테고리 | 목표 단서 |
|--------|------:|----------|-----------|
| 쉬움 | 4 | 색·국적·음료·음식 | 10~12 |
| 보통 | 4 | 위 + 동물 | 12~14 |
| 어려움 | 5 | 5개 전부 | 15 내외 |
| 매우 어려움 | 5 | 5개 전부 | 유일해 최소 집합(주로 12~14) |

- 4집 문제는 카테고리마다 원본 5개 값 중 4개를 매 문제 무작위 선택한다.
- 「새 문제」·난이도 변경 시 확인 후 새 정답 세계·단서·힌트를 생성한다.
- 생성 실패·시간 초과 시 해당 난이도 **폴백 퍼즐**로 전환하고 “기본 문제로 시작합니다”를 표시한다.

## 힌트·단서

- **단서 클릭**: 읽음/안 읽음만 토글한다(체크·취소선). 강조·힌트 공개는 하지 않는다.
- **힌트 보기**: 하단에 방향 → 관련 단서 → 확정 사실 순으로 누적한다. 준비된 힌트를 모두 보면 소진 문구가 나온다.
- **초기화**: 배치만 지운다(타이머·힌트·읽음 유지).
- **새 문제**: 배치·Undo·타이머·힌트·읽음을 모두 초기화한다.

## 글자 배율

- 오른쪽 하단 `A−` / `A+` 로 조절한다.
- 기본 **150%**, 10% 간격, **100%~200%**.
- 선택값은 `localStorage`(`einstein-text-scale`)에 저장된다.

## 교사 모드

교사 버튼·패널·정답 비교 기능은 **제거**되었다. 정답은 학생 화면에 표시되지 않는다.

## 5분 시연 스크립트

1. 규칙: 난이도에 따라 집 4~5채, 속성은 단서가 가리키는 것만 사용.
2. 「쉬움」으로 시작 → 4집·동물 행 없음 확인.
3. 단서 클릭 → 읽음만 바뀌는지 확인 → 「힌트 보기」 3회(방향→단서→사실).
4. 카드 배치·제출 → 틀린 칸 수만 안내.
5. 배율 100%·150%·200%와 「보통/어려움/매우 어려움」 전환을 시연.
