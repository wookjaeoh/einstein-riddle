# 아인슈타인 추론 게임 (수업용)

고2 대상. 단서를 읽고 5채 집에 색·국적·음료·음식·동물을 배치하는 **알고리즘 생성형** 추론 웹앱.

## 실행 방법

`einstein-riddle-app` 폴더에서:

```bash
npx --yes serve .
```

브라우저에서 안내된 주소로 `index.html`을 연다.  
(`file://` 직접 열기는 ES module 때문에 실패할 수 있음)

USB 폴더 복사·오프라인 수업도 가능. 인터넷은 `npx serve` 최초 실행 시에만 필요할 수 있다.

## 교사 모드

화면의 「교사」→ 비밀번호 `teacher2026` (학생 유인물·슬라이드에는 적지 말 것)

- **현재 생성된 판**의 정답 그리드·학생 배치 비교·단서 전체 확인
- 「새 문제」 후에도 잠금 해제 상태면 정답이 자동 갱신됨

## 생성형 난이도

| 난이도 | 목표 단서 수 | UI 도움말 |
|--------|--------------|-----------|
| 쉬움 | 12~15 | 카드 드래그·단서 하이라이트 조작 안내 |
| 어려움 | 8~11 (목표) | 단서가 더 적음을 안내 |

- 「새 문제」·난이도 변경 시 확인 후 **새 정답 세계**와 단서 집합을 생성한다.
- 목표 구간을 못 맞춰도 **유일해**인 집합이면 그대로 사용하며, 피드백에 실제 단서 개수를 표시한다.
- 현재 단서 템플릿(`sameHouse`/`atHouse`/`nextTo`/`leftOf`)상 **어려움 비폴백은 12~14개**가 나올 수 있다(설계 명세 §7.2 예외 규칙).
- 생성 실패·시간 초과 시 고전 각색 **폴백 퍼즐**로 전환하고 “기본 문제로 시작합니다”를 표시한다.

## 5분 시연 스크립트

1. 규칙: 집 5채, 속성 5종, 단서는 모두 참.
2. 「새 문제」로 판 받기 → 단서 개수 안내.
3. 단서 하나 클릭 → 하이라이트 → 카드 배치 시연.
4. 제출 시 틀린 칸 수만 보인다는 점 안내.
5. 학생이 난이도·새 문제로 개인 반복 풀이.

## 테스트 실행

자동 테스트 (Node):

```bash
node --experimental-default-type=module einstein-riddle-app/tests/run-tests.mjs
```

생성기 벤치 (선택):

```bash
node --experimental-default-type=module einstein-riddle-app/tests/benchmark-generator.mjs
```

브라우저에서 `tests/run-tests.html`을 열어 ALL PASSED 확인도 가능.
